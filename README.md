# Weather and Climate Quiz

Interactive 40-question quiz for Class 7 Geography, generated from
`WeatherAndClimateOCR.pdf` with the `html-quiz` skill.

Open `index.html` locally, or enable GitHub Pages for this repository
(settings → Pages → Deploy from a branch → main) and visit
`https://akhadir.github.io/weather-climate/`.

The quiz is a single self-contained HTML file: no internet access, libraries,
or external images are needed at view time. Add `?secs=30` to the URL for a
30-second timer per question; by default there is no time limit.
